# 皮尔逊相关系数计算 (M0-2)

## 1. 如何运行
环境要求：Python 3.x，需安装 `pyyaml`（numpy 仅用于测试验证，非核心依赖）。


支持相对路径：yaml 中的 `input_csv` 可相对于**配置文件所在目录**，也可相对于**当前工作目录**。

## 2. 输入文件格式
- **YAML 配置**：需包含 `input_csv` 字段（如 `input_csv: sample_data.csv`）。
- **CSV 数据**：需含表头，至少两列数值型数据（默认取前两列），列名自定义。

## 3. 输出结果含义
- **stdout**：正常时打印 `r = <数值>`（考官提取比对，容差 1e-6）。
- **n**：样本量；**mean**：列均值（代码计算中间量）；**r**：皮尔逊相关系数。
- **r 解读**：取值范围 [-1, 1]。1 为完全正相关，-1 为完全负相关，0 为无线性相关。
- **异常**：文件不存在/空文件/缺列/零方差时，打印可读错误到 stderr，并以**非 0 退出码**结束（无 Traceback）。

## 4. 单元测试

覆盖：[1,2,3]&[2,4,6]=1.0、[1,2,3]&[6,4,2]=-1.0、零方差(None)、缺列异常。
